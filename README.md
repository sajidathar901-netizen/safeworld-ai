SafeWorld AI 🛡️

Check Before You Trust

SafeWorld AI is an educational scam-awareness tool designed to help people identify suspicious messages, job offers, and website links.

Features

- Suspicious message screening
- Job offer warning indicators
- Website and URL pattern checks
- High, Medium, and Unclear risk indicators
- English interface with Urdu safety advice

Important Notice

This is an early rule-based prototype, not a fully developed AI system. It cannot guarantee that a message or website is safe.

Technology

- Python
- FastAPI
- HTML, CSS and JavaScript

Project Goal

To help people become more aware of online scams and make safer digital decisions.
